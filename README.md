# Land Degradation Debt
This is a standing repository for a consistent framework for assessing land degradation as an environmental ‘debt’. We propose a new way to synthesize different approaches to globally map land degradation by combining vegetation and soil indicators. Our combined approach reveals a broader lens for land degradation through global change, in particular, identifying hot-spots for the different kinds of land degradation.
All data layers can be found at JRC's [European Soil Data Centre (ESDAC)](https://esdac.jrc.ec.europa.eu/content/land-degradation-debt#tabs-0-description=0).
